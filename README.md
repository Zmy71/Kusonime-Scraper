# Kusonime-Scraper
Kusonime Scraper — scraper interaktif berbasis terminal untuk kusonime.com. Fitur: tampilan upload terbaru, pencarian anime, detail lengkap (genre, score, sinopsis, producers, dll), dan link download per resolusi dengan auto-decode Base64. Dibangun dengan Python, Requests &amp; BeautifulSoup. Tampilan berwarna dengan ANSI color.
