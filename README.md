Kusonime Scraper-- Scraper Python buat ngambil data anime dari Kusonime. Dibuat pake Python + BeautifulSoup.

✨ Fitur
- Scrape list anime terbaru
- Ambil detail anime: judul, genre, sinopsis, link download
- Export ke JSON / TXT
- Ringan & cepet

🔧 Instalasi

1. Clone repo
```bash
git clone https://github.com/zmy71/Kusonime-Scraper.git
cd Kusonime-Scraper```


2. Install dependencies
```bash
pip install requests beautifulsoup4```


🚀 Cara Jalanin
```bash
python 01.py```

📦 Requirements
- Python 3.8+
- `requests`
- `beautifulsoup4`
- `lxml`

⚠️ Disclaimer
Script ini buat tujuan edukasi. Jangan dipake buat spam request ke server Kusonime. Use at your own risk.
